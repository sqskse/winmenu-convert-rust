Легковесный и полностью фоновый конвертер видео и фото для Windows 11, написанный на **Rust**. 
Программа интегрируется в контекстное меню Windows и позволяет конвертировать файлы в один клик — без открытия лишних окон, консолей и интерфейсов.

## Особенности
- **Zero UI:** Работает абсолютно незаметно в фоне. Никаких мигающих консолей.
- **Интеграция в меню:** Добавляет аккуратное подменю «Конвертировать в» при клике правой кнопкой мыши.
- **Безопасность:** Исходный файл удаляется *только* в случае успешной конвертации. Если FFmpeg выдаст ошибку, ваш оригинал останется на месте.
- **Скорость:** Использует мощь FFmpeg и безопасность памяти Rust.

## Требования для запуска

Перед сборкой убедитесь, что на вашем компьютере установлены:
1. **Rust и Cargo** (с тулчейном MSVC) — [скачать тут](https://rustup.rs/).
2. **Visual Studio Build Tools** (обязательно с компонентом «Разработка классических приложений на C++»).
3. **FFmpeg** (должен быть добавлен в системную переменную `PATH`). Установить его можно одной командой в PowerShell:
   ```powershell
   winget install Gyan.FFmpeg

## Установка и использование

### Шаг 1. Скачивание проекта

Откройте терминал (PowerShell или встроенный в VS Code) и клонируйте репозиторий:

```powershell
git clone https://github.com/sqskse/winmenu-convert-rust.git
cd winmenu-convert-rust
```

### Шаг 2. Сборка проекта

Соберите программу в релизной версии (это займет пару минут при первом запуске):

```powershell
cargo build --release
```

### Шаг 3. Установка меню

Запустите специальный скрипт, который добавит пункт «Конвертировать в» в ваш реестр Windows:

```powershell
cargo run --bin install_menu --release
```

> В консоли должно появиться сообщение «Установщик успешно отработал!».

### Шаг 4. Как пользоваться программой

1. Найдите на компьютере любое видео или фото.
2. Нажмите на него правой кнопкой мыши.
3. Выберите «Показать дополнительные параметры» (это особенность меню Windows 11).
4. Наведите курсор на «Конвертировать в» и выберите нужный формат (например, MP4 или PNG).
5. Окно не появится, файл сконвертируется в фоне (займет пару секунд), а исходный файл автоматически заменится новым.

## Удаление

Если вы больше не хотите использовать программу, её нужно правильно удалить, чтобы очистить контекстное меню Windows.

### Шаг 1. Очистка реестра

Откройте терминал в папке с проектом и запустите скрипт удаления:

```powershell
cargo run --bin clean_menu --release
```

> Этот скрипт аккуратно удалит все созданные ключи из реестра. В консоли появится сообщение об успехе.

### Шаг 2. Удаление файлов

После очистки реестра просто удалите папку `winmenu-convert-rust` с вашего компьютера. Никаких скрытых файлов или фоновых процессов в системе не останется.
