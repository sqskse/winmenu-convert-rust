Легковесный и полностью фоновый конвертер видео и фото для Windows 11, написанный на **Rust**. 
Программа интегрируется в контекстное меню Windows и позволяет конвертировать файлы в один клик — без открытия лишних окон, консолей и интерфейсов.

## ✨ Особенности
- **Zero UI:** Работает абсолютно незаметно в фоне. Никаких мигающих консолей.
- **Интеграция в меню:** Добавляет аккуратное подменю «Конвертировать в» при клике правой кнопкой мыши.
- **Безопасность:** Исходный файл удаляется *только* в случае успешной конвертации. Если FFmpeg выдаст ошибку, ваш оригинал останется на месте.
- **Скорость:** Использует мощь FFmpeg и безопасность памяти Rust.

## 🛠️ Требования для запуска

Перед сборкой убедитесь, что на вашем компьютере установлены:
1. **Rust и Cargo** (с тулчейном MSVC) — [скачать тут](https://rustup.rs/).
2. **Visual Studio Build Tools** (обязательно с компонентом «Разработка классических приложений на C++»).
3. **FFmpeg** (должен быть добавлен в системную переменную `PATH`). Установить его можно одной командой в PowerShell:
   ```powershell
   winget install Gyan.FFmpeg
